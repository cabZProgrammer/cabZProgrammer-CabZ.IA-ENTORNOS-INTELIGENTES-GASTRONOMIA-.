# 🏛️ CabZ.IA - Entornos Inteligentes (GASTRONOMíA)

Bienvenido al repositorio oficial de **CabZ.IA**, un ecosistema operativo modular y escalable (Micro-SaaS) diseñado exclusivamente para la modernización del sector gastronómico (Hoteles, Restaurantes y Cafeterías)[cite: 6]. 

Nuestra visión supera el concepto de software tradicional: construimos **Entornos Inteligentes** donde la Inteligencia Artificial (IA) automatiza, predice y optimiza desde las compras de inventario hasta la retención de clientes[cite: 6].

## 🧩 Arquitectura "Plug & Play" (Micro-SaaS)
El ecosistema CabZ.IA está desarrollado bajo una arquitectura 100% modular. Mantenemos un 80% de sistemas estandarizados altamente robustos, permitiendo personalizar el 20% restante (identidad, colores y flujos específicos) para cada cliente en tiempo récord[cite: 6].

## 📊 Dominios Operativos Integrados (Los Módulos)

### 1. Dirección Estratégica y Finanzas (Core)
- **`DashboardOperativo.tsx`**: Panel gerencial unificado de ventas y monitor de obrador.
- **`AsistenteCEO.tsx`**: Interfaz conversacional por voz (NLP) para generar resúmenes ejecutivos instantáneos.
- **`GemeloDigital.tsx`**: Motor predictivo IA para simular variaciones de precios y demanda sin riesgo.
- **`CalculadoraPrecios.tsx`**: Ingeniería financiera exacta para proteger el Margen Real de rentabilidad.
- **`GestorOPEX.tsx`**: Vigilancia IA de gastos operativos para detección temprana de fugas de capital.

### 2. Producción y Abastecimiento (Back of House)
- **`EscandalloPro.tsx`**: Estandarización de recetas y costeo al gramo.
- **`EscaladorRecetas.tsx`**: Recálculo lógico de ingredientes con alertas de capacidad física (ej. amasadoras).
- **`AuditorFacturasIA.tsx`**: Escáner de visión artificial que extrae insumos y costos de facturas.
- **`KardexInteligente.tsx`**: Control PEPS con alertas predictivas de agotamiento.
- **`NegociadorProveedores.tsx`**: Bot B2B que cotiza insumos automáticamente con múltiples proveedores.

### 3. Operaciones de Sala y Clientes (Front of House)
- **`POSConversacional.tsx`**: Punto de venta (caja) operado mediante lenguaje natural para eliminar la curva de aprendizaje.
- **`GestorReservas.tsx`**: Optimizador espacial ("Tetris" de mesas) para maximizar la capacidad del salón.
- **`MenuQRDinamico.tsx`**: Vitrina digital interactiva que se adapta al clima y oculta platos sin stock.
- **`WhatsAppBotManager.tsx`**: Configuración del mesero virtual IA 24/7 con capacidad de *upselling*.

### 4. Marketing, RRHH e Infraestructura
- **`IngenieriaMenuIA.tsx`**: Clasificador estratégico de platos (Estrellas, Caballos de Batalla, Perros).
- **`CRMPredictivo.tsx`**: Sistema de recuperación de clientes VIP mediante promociones automáticas.
- **`GeneradorTurnosIA.tsx`**: Creador de mallas horarias cruzando picos de demanda y evitando fatiga laboral.
- **`MonitorIoT.tsx`**: Mantenimiento predictivo mediante sensores para predecir daños en neveras y hornos.
- **`GeneradorReportesSanidad.tsx`**: Redactor automático de auditorías de cadena de frío y saneamiento (INVIMA/FDA).

## 🎨 Sistema de Diseño: "Calma Artesanal"
Diseñado para reducir la carga cognitiva en entornos de alta presión comercial:
- **Fondos y Superficies:** Crema Harina (`#F6F2E9`) y Blanco Cálido (`#FFFFFF`)[cite: 6].
- **Acentos Funcionales:** Verde Romero (`#3D5A2A`) para el flujo principal[cite: 6].
- **Ingeniería Tipográfica:** Uso de fuentes monoespaciadas tabulares (`tabular-nums`) para precisión visual en finanzas[cite: 6].
- **Cumplimiento WCAG:** Contrastes accesibles validados para todo tipo de pantallas[cite: 6].
