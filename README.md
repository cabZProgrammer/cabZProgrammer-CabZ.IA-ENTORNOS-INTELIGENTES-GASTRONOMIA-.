# 🏛️ CabZ.IA - Entornos Inteligentes (Gastronomía)

Bienvenido al repositorio oficial de **CabZ.IA**, el ecosistema operativo modular y escalable diseñado específicamente para la modernización del sector HORECA (Hoteles, Restaurantes y Cafeterías).

Este proyecto no es una simple aplicación aislada; es un **Entorno Inteligente** donde la Inteligencia Artificial organiza, optimiza y automatiza múltiples procesos del negocio para convertir entidades caóticas en máquinas escalables[cite: 2].

## 🧩 Arquitectura "Plug & Play" (Micro-SaaS)
El sistema está construido bajo una arquitectura modular (80% base estándar / 20% personalización del cliente)[cite: 1]. Esto permite ensamblar soluciones de software a medida de forma ultrarrápida.

### 📊 Dominios Operativos Integrados:
1. **Dominio de Gestión y Finanzas:** Calculadoras de rentabilidad con margen real, auditor de facturas por visión artificial y optimizador de gastos OPEX[cite: 2].
2. **Dominio de Producción (Back of House):** Creador de recetas estándar (Escandallos), escalador lógico de ingredientes y Monitor KDS Predictivo[cite: 2].
3. **Dominio de Inventario:** Kardex autónomo PEPS con predicción de compras basada en IA[cite: 2].
4. **Dominio Comercial (Front of House):** POS Conversacional, Gestor de Reservas "Tetris" y Menú QR dinámico adaptable al clima[cite: 2].
5. **Dominio de Marketing y RRHH:** CRM predictivo de fidelización y mallas de turnos generadas por IA[cite: 2].

## 🎨 Sistema de Diseño: "Calma Artesanal"
Toda la interfaz de usuario está construida para reducir la carga cognitiva en entornos de alta presión (como cocinas comerciales), utilizando:
- **Colores Base:** Crema Harina (`#F6F2E9`) y Blanco Cálido (`#FFFFFF`)[cite: 2].
- **Acentos:** Verde Romero (`#3D5A2A`) para acciones principales[cite: 2].
- **Tipografía Financiera:** Uso estricto de fuentes monoespaciadas (`tabular-nums`) para alinear precios y gramajes a la perfección[cite: 1].
- **Accesibilidad:** Contraste validado (WCAG 2.1 AA/AAA)[cite: 1].

## 🛠️ Stack Tecnológico
- **Frontend:** React (TypeScript / .tsx)
- **Estilos:** Tailwind CSS
- **Iconografía:** Lucide-React
- **Motor Lógico / Cerebro:** Generación Aumentada y Análisis mediante Google Gemini AI (LLMs)
